# Shared engine ABI and bridges

`universal-bridge.cc` is compiled once for MicroFreak 5.0.0.2084's Cortex-M4 Thumb hard-float ABI. It uses the MIT-licensed Mutable Instruments `stmlib/utils/buffer_allocator.h` header and C++11. Build with clang++ and `--target=arm-none-eabi -mcpu=cortex-m4 -mthumb -mfpu=fpv4-sp-d16 -mfloat-abi=hard -Oz -fno-builtin -fno-exceptions -fno-rtti -ffunction-sections -fdata-sections`. `portable-route.S` is assembled for the same Thumb target. `retired-engine.cc` supplies the shared silent/no-op ABI used by explicitly retired slots.

The exported universal bridge contains `native_alias_init`, `native_alias_parameter` and a volatile 23-word binding table. After verifying the immutable module hash, the browser relocates its sections and supplies runtime ABI table addresses for selected IDs. The same bridge serves all 22 destinations. DSP modules contain their own ABI entries and object/scratch requirements; library version 3 derives compatible choices from those requirements and the shared host contract rather than per-pair transport lists.

Every voice uses the original Chords object region (336 bytes) and its offered scratch arena (16,384 bytes). On activation, the bridge invokes the original frontend initialization and restores the visible model ID. It preserves the first 16 object bytes, including frontend postprocessing settings, and clears bytes 16–335 plus the scratch arena before calling module Init and activation. This makes engine state independent of the previously active slot even when Chords itself is retired. Unbound IDs retain their original routes.

`v2/universal.js` combines all module sections, ABI tables, labels, bindings and configuration into one placement problem. Library regions carry original-byte hashes and required retired owners. Native-family Render code is eligible only when every family member is explicitly retired; otherwise it remains intact. Empty is an explicit silent replacement. The composer never manufactures extra retirements to make a selection fit. A separate verifier in `v2/verify-universal.js` checks changes against original bytes and derives eligible regions independently of the composer's edit list.

The shared UI formatter selects continuous or discrete original formatting from engine metadata. Replacing Vocoder also replaces its per-voice pointer setup and six Type-14 CV exclusions so the selected replacement reaches the ordinary four-voice audio route; retaining Vocoder preserves those bytes. These routing changes have native/WASM execution coverage; they are not a claim of physical acceptance.

`portable-bridge.cc` remains the earlier version-2 implementation, retained with the frozen test library for compatibility regression. The current version-3 library uses `universal-bridge.cc`; modules are compiled once, never during a user's selection. Two legacy-only module objects remain available for the earlier tests.
